About

                

                    cyber-barista is a small offline version of the CyberChef idea. Pick operations from the
                    palette, order them, set each one to encode or decode, and the input is passed through
                    the chain from top to bottom. Every step takes bytes and returns bytes, so binary output
                    survives into the next step.
                    


                    Everything runs client side. There is no network call, no analytics and no dependency:
                    hashing uses the browser's WebCrypto, compression uses the browser's own gzip and deflate
                    streams, and MD5 and CRC-32 are implemented in the file because WebCrypto does not offer them.
                    


                    MD5, CRC-32, ROT and XOR are here for analysis and legacy formats, not for protecting
                    anything. The recipe and the input are kept in this browser's local storage so the page
                    survives a reload, and a saved recipe contains any key or secret typed into a step. Use
                    Reset to clear both.
